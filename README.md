# Sistema de Desconto Progressivo

Programa desenvolvido em Python para calcular o desconto de uma compra de acordo com o valor informado pelo usuário.

## Regras de desconto

- Compras abaixo de R$ 200,00: 5% de desconto.
- Compras de R$ 200,00 até R$ 299,99: 10% de desconto.
- Compras a partir de R$ 300,00: 15% de desconto.

## Como funciona

O usuário informa o valor total da compra. O programa identifica a porcentagem de desconto correspondente, calcula o valor do desconto e apresenta o total que deverá ser pago.

## Tecnologias utilizadas

- Python
- Visual Studio Code
